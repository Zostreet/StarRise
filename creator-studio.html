About saved projects

This studio saves to the current browser. Anyone using the same browser profile may be able to open those projects. Clearing browser data can remove them. Keep exported backups for important work. Recording supports one microphone take at a time with playback of the existing session. Cloud sharing is optional and requires a signed-in adult account. Only the session owner and accepted collaborators can access published project files. Cloud versions are snapshots you publish deliberately, with a 50 MB limit per version; local edits do not sync automatically. Downloaded files remain with their recipients after access is removed. This workspace does not replace recording hardware, a mastering engineer, or distribution to streaming platforms.
